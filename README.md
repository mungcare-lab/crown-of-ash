# 크라운 오브 애쉬 · CROWN OF ASH

멸망한 왕국의 재 위에서, 서약은 다시 세워진다.

- **플레이:** https://mungcare-lab.github.io/crown-of-ash/
- **버전:** Phase 1 — 싱글플레이 웹 빌드 (2D 아이소메트릭 · 실시간 타깃 전투)
- **무대:** 에르바니아 대륙 · 브렌포트 마을

## 조작

| 동작 | 키 |
|---|---|
| 이동 | `W` `A` `S` `D` (8방향) |
| 대상 지정 | 화면 클릭 |
| 기본 공격 | `Space` (대상 지정 후) |
| 스킬 1~3 | `1` `2` `3` |
| 생명 회복액 / 마나 회복액 | `4` `5` |
| 인벤토리 / 캐릭터 / 스킬 | `I` `C` `K` |
| 퀘스트 / 지도 / 설정 | `Q` `M` `Esc` |

모바일: 좌하단 조이스틱으로 이동, 우하단 스킬 버튼으로 시전.

## 이 저장소에 대해

`dist/` 빌드 산출물만 배포되는 정적 사이트입니다. 진행 상황은 브라우저 로컬 저장소에 보관됩니다.
